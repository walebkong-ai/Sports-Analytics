# Sports Analytics Workbench

A dependency-free sports analytics dashboard prototype for comparing two basketball teams with sample data.

## What is included

- Team and opponent selectors
- Summary metrics for net rating, win chance, factor edge, and rotation trust
- Last-12-game trend chart with net, offense, and defense views
- Four factors comparison
- Shot profile visualization
- Matchup scenario sliders for pace, turnovers, and home court
- Sortable player efficiency table

## Run it

Open `index.html` in a browser. No package install or local server is required.

## Data

The current teams and stats are sample data stored in `app.js`. Replace the `teams` array with your own feed or exported model results when you are ready to connect real data.
